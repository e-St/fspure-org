What this site does (and doesn’t)

Pages are static HTML. We do not set cookies, run analytics, show ads, or offer accounts or newsletters. Nothing here is used for profiling or marketing.

The initializer form on this site runs in your browser. The fine-grained PAT you type is sent only to api.github.com to open a pull request on the control repo you name. This site does not store the PAT (GitHub Pages has no server backend of ours). GitHub processes that request under GitHub’s privacy statement.

Hosting (GitHub Pages)

The site is served by GitHub Pages (GitHub, Inc., USA). When you load a page, the host may process usual request data such as IP address, time, URL, and browser user-agent — as almost any web host does. See GitHub’s privacy statement.

External links

Links to GitHub and other sites leave this page. Those sites have their own policies. We do not embed social plugins or third-party trackers.
